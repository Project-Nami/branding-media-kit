# Figures (`_`)

Illustrations for [the Media Kit](../README.md): specimen cards, clear-space and minimum-size
diagrams, the incorrect-usage grid, palette sheets and swatch chips, the Satoshi type specimen,
the naming graphic, and the download button. Each one is drawn from the official assets in
[`../brand-kit/`](../brand-kit).

Most are a `-light` / `-dark` pair, selected with `<picture>` in the README so they follow the
reader's theme.

> [!WARNING]
> Not brand assets. These show the logo at fixed sizes, distorted (to demonstrate misuse), and
> under annotation overlays. Use the official files in [`../brand-kit/`](../brand-kit).
